# Workshop Model Assets

The full image stores one immutable copy of all four model files and the validated `gfx1100` MIGraphX cache under `/opt/ultralytics-yolo26/models`. The pipeline reads this directory directly. Since llama.cpp runs in a separate image, the launcher checksum-copies the same model set once to the named volume `ultralytics_yolo26_models` and mounts it read-only at `/models`. The first Notebook cell calls `scripts/model_setup.py`, but `ULTRALYTICS_WORKSHOP_BUNDLE=baked` forces strict offline verification: a missing or corrupt file is an error and cannot trigger a download.

Radeon Cloud defaults to the reachable proxy for the same release assets. Override either URL when required:

```bash
export YOLO_CHECKPOINT_URL=https://github.com/ultralytics/assets/releases/download/v8.4.0/yolo26x.pt
export YOLO_ONNX_URL=https://github.com/ultralytics/assets/releases/download/v8.4.0/yolo26x.onnx
```

The step-by-step notebook can execute a real checkpoint export with `RUN_EXPORT=1`. It writes to `output/export/`; it does not overwrite the strictly verified release ONNX used by the classroom fast path.

## ORT MIGraphX Cache

The baked image carries the cache matching its pinned W7900D/gfx1100 runtime. Other GPU/runtime identities are generated by the Ultralytics ONNX backend on first inference:

```text
models/ort-migraphx-cache/<identity>/
├── identity.json
└── *.mxr
```

`identity.json` binds the ONNX SHA-256, GPU architecture/name, PyTorch/HIP, MIGraphX, ONNX Runtime, Ultralytics version/commit, workshop patch SHA, FP16 mode, and input/output contracts. The `.mxr` is a target-specific cache, not a portable model artifact.

The baked cache is a startup optimization, not a portable binary: an identity mismatch selects a new directory and recompiles safely.

## Development Fallback Download

This path is for a source checkout or a non-full development image only. It is not used by the published full release.

```bash
unset ULTRALYTICS_WORKSHOP_BUNDLE
export HF_ENDPOINT=https://hf-mirror.com
python3 scripts/model_setup.py
```

Optional controls:

```bash
export MODEL_DOWNLOAD_ATTEMPTS=8
export ULTRALYTICS_YOLO26_MODEL_DIR=/path/to/models
```
